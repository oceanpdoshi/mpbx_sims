The parallelization hierarchy is:
Level 1: 1 task = 1 waveguide geometry.

In the case of a single waveguide geometry, this 1 task will be allotted 48 cores and 192GB of memory (1 full node, all to itself). See the --cpus-per-task, and note that these can be adjusted in the script. 

It may be advantageous for multi-geometry sweeps to reduce the number of cores <-> memory per task, so that more tasks can be run concurrently. The way to think about it, is that a node has 48 cpus, so you could submit tasks that use 1,2 , 4, 8, 16, or 24 cpus since  those are factors of 48. You can then run more tasks concurrently.
